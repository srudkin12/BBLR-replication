# BBLR Paper 1 replication materials

Replication release candidate for:

**Regularising Local Affine Fields under Uneven Local Information: Ball-Based Linear Regression**

Authors: Paweł Dłotko, Sylwester Piątek, Simon Rudkin, Rafał Topolnicki.

## Scope

These materials support the estimator/mechanism/operating-region evidence in Paper 1. They do not include the distinct Paper 2 simultaneous-inference programme or Paper 3 adaptive-geometry programme.

BBLR is implemented as a two-stage regularisation of a generated local affine field. The exact zero branch preserves `BBLR(r,0)=LLR(r)`.

## Repository map

- `code/01_operating_map/` — 92-cell univariate operating map.
- `code/02_strong_comparators/` — strong-comparator suite.
- `code/03_bivariate/` — broad, support-aware and fine-locality bivariate designs.
- `code/04_matched_hlambda/` — matched-H-lambda mechanism and stable-arithmetic audits.
- `code/05_affine_field_replay/` — legacy coefficient-field/tangent-intercept replay.
- `code/06_higher_dimension/` — 82-cell higher-dimensional production study.
- `code/07_local_sparse/` — local sparse comparator audit.
- `code/08_uncertainty/` — noise and global uncertainty audits.
- `code/09_electricity/` — grouped-primary electricity and coefficient-validation analyses.
- `evidence/` — compact returned evidence selected from validated HANDbacks.
- `provenance/` — archive hashes, staging audit, exclusions and external archive ledger.
- `manuscript_outputs/` — reserved for a final manuscript table/figure reconstruction layer.

## Full production HANDbacks

Large production HANDbacks are not duplicated wholesale in this GitHub-efficient release. `provenance/EXTERNAL_ARCHIVE_MANIFEST.csv` records each archive's exact SHA-256, size and role. Compact manuscript-facing evidence is retained under `evidence/`.
