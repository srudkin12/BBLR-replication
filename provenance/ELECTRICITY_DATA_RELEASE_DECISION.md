# Electricity data release decision

## Decision

Paper 1's public replication repository does **not** distribute the electricity observations.

Source/input copies formerly present in the release candidate have been removed. The public repository retains analysis code, frozen selections, compact derived results and provenance.

Replicators should follow `../DATA_AVAILABILITY.md` to obtain and reconstruct the electricity inputs locally.

## Scope

This decision concerns the empirical observation data only. It does not remove manuscript-facing numerical summaries, fitted-curve summaries, bootstrap summaries, frozen selection records, or figures generated by the accepted analysis.

## Repository policy

Generated files under the electricity `source_data/` directories are local working files and are ignored by Git.
